**Inversion of control** -- Inversion of Control (IoC) is a design principle in Java where the control of creating and managing objects is transferred from your application code to a framework or container.

Instead of your code creating its dependencies, the framework provides them.

### Dependency Injection (DI) 
- Lets say Class A needs Class B. How does B get into A?
1) Constructor Injection
2) Setter Injection
3) Field Injection
4) Method Injection
